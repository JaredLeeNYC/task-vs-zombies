# 任务大战僵尸

一个植物大战僵尸玩法的待办工具：每天上班打开它，它就告诉你今天按什么顺序打哪些任务、各打多久。

## 玩法

- **任务是僵尸。** 重要度决定头盔（普通 / 路障 / 铁桶），预计耗时是血量，五条车道是五类工作。
- **离房子的距离是“最晚还有几个工作日必须开工”。** 紧挨房子的那一列今天必须处理；一天干不完的大任务会提前逼近。
- **僵尸会走。** 工作时间内（默认 9–18 点，可在设置里改）它从所在格子的右边走到左边，过一夜跨进下一格，到期当天下班时走到门口。
- **房子有 100 点生命。** 过了截止日期还活着的僵尸每个工作日啃一口（普通 5、路障 10、铁桶 15），被打死那天也算；每周一修好。
- **专注时间是阳光。** 每天的阳光（默认 300 分钟）按威胁度分给最该打的僵尸，得到右侧的“今日作战计划”，从上往下打即可。
- **开火** 是一次专注计时（默认 25 分钟），计入任务进度；**击杀** 是完成；**推迟** 是今天不打；没排进今天的可以点 **今天打** 强行拉入。
- **墓碑** 是循环任务，到了指定的星期几自动爬出一只当天到期的僵尸。
- 今天必须处理的任务排不下时，计划顶部会出现“防线告急”。

## 快速录入

在顶部输入框里写标题，旁边用空格隔开加标记，回车放进草坪：

```
写周报 !3 45m 周五 #会议
站会 每个工作日 15m #会议
```

| 标记 | 含义 |
| --- | --- |
| `!1` `!2` `!3`（或 `!` `!!` `!!!`） | 重要度 |
| `45m` `1.5h` `30分钟` `2小时` | 预计耗时 |
| `今天` `明天` `后天` `周五` `下周一` `12-01` `2027-03-08` `+3d` | 截止日期 |
| `#车道名` 或 `#1`～`#5` | 车道 |
| `每天` `每个工作日` `每周一三五` | 立一块墓碑，定期复活 |

## 运行

```
pnpm install
pnpm dev      # 开发
pnpm build    # 生成单文件 dist/index.html，双击即可打开，无需服务器
pnpm test     # 排期、解析、状态规则的测试
```

存档在浏览器的 localStorage 里（键 `pvz-todo:v1`），按打开的网址区分，没有后端。

## 代码结构

- `src/core/plan.ts`：威胁度评分和今日计划（纯函数）。
- `src/core/house.ts`：房子生命值和一天的进度，都由任务和当前时间算出，不单独存档。
- `src/core/game.ts`：全部状态变更（reducer）。
- `src/core/parse.ts`：快速录入的标记解析。
- `src/core/dates.ts`：按工作日计算的日期工具。
- `src/ui/`：草坪、计划面板和各个对话框。
- `src/ui/scene/`：草坪的 three.js 场景。`LawnScene.ts` 管镜头、动画和把 HTML 标签贴到模型上，`models.ts` 用几何体搭僵尸、豌豆射手、墓碑和房子。
